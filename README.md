# Свободное время — Android-приложение

Трекер свободных окон на 7 дней. Читает **календарь телефона**: все аккаунты, которые
есть в Android (Google, Outlook/Teams, Samsung, локальный), и показывает, когда вы свободны.

Как устроено:

- `app/src/main/assets/index.html` — интерфейс (HTML + JS). Меняйте его как обычную страницу.
- `MainActivity.java` — показывает страницу во WebView и передаёт ей объект
  `window.AndroidCalendar` с методами:
  - `hasPermission()` → `true/false`
  - `requestPermission()` → системный запрос доступа к календарю
  - `getCalendars()` → JSON со списком календарей телефона
  - `getEvents(fromMs, toMs)` → JSON с событиями, повторяющиеся уже развёрнуты
- Разрешение одно: `READ_CALENDAR` (только чтение). Интернета у приложения нет.

## Вариант 1. Android Studio

1. Распакуйте архив и откройте папку `FreeTime` в Android Studio (File → Open).
2. Дождитесь окончания синхронизации Gradle (первый раз 3–10 минут, нужен интернет).
3. Build → Build App Bundle(s) / APK(s) → **Build APK(s)**.
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

## Вариант 2. Без установки, через GitHub

1. Создайте репозиторий на github.com и загрузите в него все файлы из папки `FreeTime`
   (вместе со скрытой папкой `.github`).
2. Откройте вкладку **Actions**: сборка «Собрать APK» запустится сама (≈5 минут).
3. Откройте завершённый запуск → внизу раздел Artifacts → скачайте **FreeTime-apk**.

## Установка на телефон

1. Перекиньте `app-debug.apk` на телефон (Telegram «Избранное», Google Диск, кабель).
2. Откройте файл и разрешите установку из этого источника.
3. При первом запуске нажмите «Разрешить доступ» к календарю.

## Встречи из Teams

Teams хранит встречи в календаре Outlook. Чтобы они попали в календарь телефона:

1. Установите **Microsoft Outlook** на Android и войдите рабочим аккаунтом.
2. Outlook → Настройки → ваш рабочий аккаунт → включите **«Синхронизировать календари»**.
3. В приложении «Свободное время» → «Настройки расчёта» отметьте этот календарь.

Если пункта синхронизации нет или он не включается, это ограничение корпоративной политики
(Intune) — тогда нужно разрешение IT.

## Настройки внутри приложения

- Начало и конец дня (по умолчанию 06:00–22:00).
- Минимальная длина окна (по умолчанию 30 мин).
- Рабочие часы по будням (по умолчанию 09:00–18:00). Если встречи Teams уже подтягиваются,
  этот блок можно выключить.
- Какие календари учитывать — например, снять галочку с «Праздников» или «Дней рождения».
